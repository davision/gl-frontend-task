# Frontend Developer - Assessment Task

## Task

Build a casino finder inspired by:

- [PlayUSA Casino Finder](https://www.playusa.com/casino-finder/)
- `promoguy.us`
- The provided Figma design

Ask the user a few questions, one at a time. Use the answers to recommend a casino and bonus.

## Requirements

- Responsive on mobile and desktop
- Load questions and casino data from the Symfony API
- Make the answers affect the recommendation
- Include back, next, progress and validation
- Handle loading, empty and error states
- Use reusable and easy-to-understand Vue components
- Style the final bonus cards close to the design
- Complete the provided Symfony-rendered page at `/twig-preview`
- Render all casino bonuses there using reusable Twig templates and the provided data
- Keep the Twig page responsive and do not use Vue on it
- Avoid unnecessary dependencies and hardcoded content

## Delivery

Fork this repository and create pull request when done.

Use many clear commits showing how the solution developed.

Update `README.md` with your approach and any unfinished work. Keep the existing setup, test and build instructions working.
